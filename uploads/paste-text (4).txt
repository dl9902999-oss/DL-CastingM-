以下內容可直接貼到 **Lovable**，作為新增 **鑄造廠－模具管理模組（Pattern / Mold Management Module）** 的需求規格。

---

# 專案名稱

新增「模具管理模組（Pattern Management）」

---

# 功能目標

建立一套完整的鑄造模具管理系統，管理：

* 模具基本資料
* 模具版本管理
* 模具壽命管理
* 模具維修保養
* 模具庫存位置
* 模具借出／歸還
* 模具與產品綁定
* 模具與工單串接
* 模具生產履歷
* 模具成本分析

模組需與既有：

```text
工單管理
批次造模
熔解管理
品質管理
入庫出貨
```

互相串接。

---

# 功能入口

新增左側選單：

```text
模具管理
├─ 模具總覽
├─ 模具建檔
├─ 模具保養
├─ 模具履歷
├─ 模具庫存
├─ 模具分析
```

# 模組一【模具基本資料】

每組模具一筆。

欄位：

| 欄位     | 型態       | 必填 |
| ------ | -------- | -- |
| 模具編號   | Auto     | 是  |
| 模具名稱   | Text     | 是  |
| 產品料號   | Dropdown | 是  |
| 客戶名稱   | Dropdown | 否  |
| 模具類型   | Dropdown | 是  |
| 材質     | Text     | 否  |
| 模穴數    | Number   | 否  |
| 尺寸     | Text     | 否  |
| 重量(kg) | Decimal  | 否  |
| 開模日期   | Date     | 否  |
| 供應商    | Dropdown | 否  |
| 採購成本   | Decimal  | 否  |
| 壽命次數   | Integer  | 否  |
| 目前使用次數 | Auto     | 是  |
| 剩餘壽命   | Auto     | 是  |
| 狀態     | Enum     | 是  |
| 備註     | Textarea | 否  |

模具類型：

```text
木模
樹脂模
金屬模
砂模
殼模
芯盒
其他
```

狀態：

```text
待驗收
可生產
維修中
停用
報廢
```

自動計算：

```text
剩餘壽命
=
壽命次數
-
目前使用次數
```

# 模組二【模具版本管理】

支援模具變更紀錄。

欄位：

|版本|變更日期|變更內容|圖面|建立人|

規則：

```text
V1.0
V1.1
V2.0
```

功能：

* 上傳圖檔
* 保留歷史版本
* 可回復舊版

支援：

```text
PDF
DWG
DXF
STEP
JPG
PNG
```

# 模組三【模具履歷】

自動累積。

顯示：

|日期|工單|產品|數量|造模數|操作員|

來源：

```text
批次造模完成
自動寫入
```

自動更新：

```text
使用次數＋1
```

# 模組四【模具保養】

功能：

保養提醒。

欄位：

|保養日期|類型|內容|費用|下次保養|

類型：

```text
清潔
補修
加工
翻修
更換
```

規則：

達條件提醒：

```text
使用達100次
距離上次30天
```

通知：

```text
系統提醒
Email
APP通知
```

# 模組五【模具庫存】

管理模具位置。

欄位：

|模具編號|倉庫|區域|貨架|位置|

範例：

```text
A倉
3區
A-02
```

狀態：

```text
在庫
借出
維修
使用中
```

功能：

* 掃碼查詢
* 快速定位
* 庫位移轉
