既然你已經用 Lovable 做出一套鑄造管理系統，我會建議品質檢驗不要只做「輸入結果」，而要做成 **製程節點式品質管理（Process Quality Control）**，讓資料可以一路追溯到：

**工單 → 造模 → 熔解 → 澆注 → 清砂 → 熱處理 → 檢驗 → 入庫**

下面這份可以直接貼給 **Lovable**。

---

# 專案名稱

新增／優化「品質檢驗管理模組（Quality Inspection Module）」

---

# 功能目標

建立完整鑄造品質流程，支援：

* 首件檢驗（FAI）
* 製程檢驗（IPQC）
* 最終檢驗（FQC）
* 出貨檢驗（OQC）
* 缺陷分析
* 不良追溯
* CAPA（矯正預防）
* 品質 KPI

所有檢驗需可追溯至：

```text
工單
批次
模具
熔解爐次
操作員
產品
客戶
```

---

# 模組一【首件檢驗 FAI】

目的：

第一件確認是否可量產。

欄位：

| 欄位   | 型態        |
| ---- | --------- |
| 工單   | 關聯        |
| 產品   | 自動        |
| 批次   | 關聯        |
| 模具   | 自動        |
| 熔解紀錄 | 關聯        |
| 檢驗日期 | Datetime  |
| 檢驗員  | User      |
| 判定   | Pass/Fail |

檢驗項目：

```text
尺寸
重量
外觀
成份
硬度
外觀缺陷
```

結果：

```text
通過
退回調整
重做
```

規則：

未通過：

```text
禁止進入量產
```

# 模組二【製程檢驗 IPQC】

目的：

生產中監控。

抽驗設定：

```text
每20件
每30分鐘
每批次
```

檢查項目：

| 項目   |
| ---- |
| 尺寸   |
| 外觀   |
| 重量   |
| 溫度   |
| 砂模狀況 |
| 氣孔   |
| 縮孔   |
| 裂紋   |

欄位：

```text
抽樣數
合格數
不良數
良率
```

公式：

```text
良率
=
合格數
÷
抽樣數
×100
```

異常：

```text
通知主管
暫停工單
```

# 模組八【品質 KPI】

首頁看板：

① 一次合格率 FPY

公式：

```text
一次合格數
/
總生產數
×100
```

---

② 不良率

```text
不良數
/
總產量
×100
```

---

③ 不良 Pareto

排行：

```text
前10大缺陷
```

---

④ 客訴率

```text
客訴批次
/
出貨批次
```

---

⑤ 重工率

```text
重工數
/
總數
```

---

⑥ 材質別良率

比較：

```text
SC46
SCM440
SCS13
316L
…
```
