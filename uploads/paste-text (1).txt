可以，而且這個設計已經接近鑄造廠的 **熔解管理（Melting Management / Heat Record）** 模組，不只是紀錄用途，後續也能直接延伸做 **能耗分析、配料追溯、成分良率、成本分析**。

我會建議拆成 **主表（熔解批次）＋明細表（投料）＋成份表（化驗）**，避免之後欄位爆炸。

# ① 熔解紀錄（主表：melt_records）

一爐一筆。

| 欄位                  | 型態       | 說明               | 自動 |
| ------------------- | -------- | ---------------- | -- |
| id                  | UUID     | 系統編號             | ✓  |
| melt_date           | Date     | 日期               |    |
| material_grade      | Text     | 材質（SCM440、316L…） |    |
| furnace_no          | Text     | 爐號               |    |
| power_kwh           | Decimal  | 耗電度數(kWh)        |    |
| power_start_time    | Datetime | 開始送電時間           |    |
| tap_time            | Datetime | 出湯時間             |    |
| melt_minutes        | Formula  | 熔解時間(分鐘)         | ✓  |
| tap_temp            | Decimal  | 出爐溫度(℃)          |    |
| total_charge_weight | Decimal  | 總投料重量(kg)        | ✓  |
| specific_energy     | Formula  | 能耗(kWh/kg)       | ✓  |
| created_by          | User     | 建立人              |    |
| remark              | Text     | 備註               |    |

---

### 自動公式

熔解時間：

```text
DATEDIFF(tap_time,power_start_time)
```

總投料重量：

```text
SUM(投料重量)+SUM(二次添加重量)
```

能耗：

```text
power_kwh / total_charge_weight
```

範例：

```text
耗電=1850 kWh
總投料=2200kg

能耗=0.84 kWh/kg
```

# ② 投料明細（melt_materials）

一爐可多筆。

| 欄位               | 型態      | 說明   |
| ---------------- | ------- | ---- |
| id               | UUID    |      |
| melt_id          | FK      |      |
| raw_material     | Text    | 原料名稱 |
| charge_weight    | Decimal | 首次投料 |
| secondary_weight | Decimal | 二次添加 |
| subtotal         | Formula |      |

---

### 原料範例

| 原料   |   首次 | 二次 |
| ---- | ---: | -: |
| 回爐料  | 1200 |  0 |
| 廢鋼   |  500 |  0 |
| FeSi |   30 | 10 |
| FeMn |   20 |  5 |
| 增碳劑  |   10 |  5 |
| Ni   |   80 | 10 |

公式：

```text
subtotal=
charge_weight+secondary_weight
```

## 化學成份欄位

| 元素 | 欄位 |
| -- | -- |
| 碳  | C  |
| 矽  | Si |
| 錳  | Mn |
| 磷  | P  |
| 硫  | S  |
| 鎳  | Ni |
| 鉻  | Cr |
| 鉬  | Mo |
| 銅  | Cu |
| 鐵  | Fe |

資料型態：

```text
Decimal(5,3)
```

範例：

| 階段 |    C |   Si |   Mn |    P |    S |   Ni |   Cr |  Mo |  Cu |  Fe |
| -- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --: | --: | --: |
| 目標 | 0.18 | 0.60 | 0.80 | 0.03 | 0.02 | 10.5 | 16.8 | 2.1 | 0.3 | Bal |
| 爐中 | 0.17 | 0.58 | 0.75 | 0.03 | 0.02 | 10.4 | 16.6 | 2.0 | 0.3 | Bal |
| 爐後 | 0.18 | 0.61 | 0.80 | 0.02 | 0.01 | 10.6 | 16.9 | 2.1 | 0.3 | Bal |

※ Fe 建議可：

```text
Fe = 100 - 其他元素總和
```

自動計算。
